# AI-Job — tech-spec

## Как устроено сейчас

Статический сайт без сборки и без бэкенда. Стартовая версия — `vibejobs-demo`: HTML-страницы, один `style.css`, два скрипта.

- `data.js` — все данные демо: вакансии, компании, новости, курсы, инструменты, статьи. Единый источник правды для списков.
- `common.js` — общая шапка и подвал, меню «Ещё» и «Разместить», избранное (localStorage), уведомления.
- `style.css` — цвета через переменные в `:root`, тёмная тема через `prefers-color-scheme` и `data-theme`.
- Страницы: `index.html` (вакансии), `vacancy.html`, `place.html` (конструктор, 4 шага), `quick.html`, `resume.html`, и информационные разделы.

## Логика

- Фильтры и поиск на `index.html` работают на клиенте: список `SITE.jobs` фильтруется по состоянию `state`, затем рендерится.
- Клик по чипу «Все» сбрасывает запрос; поиск и теги показывают запрос рядом со счётчиком.
- Избранное и резюме хранятся в `localStorage` браузера, на сервер ничего не уходит.
- Конструктор вакансии: шаги переключаются через атрибут `hidden`, валидация на шагах 1, 3 и 4. Подсказки берутся из объекта `HINTS` по направлению.

## Откуда данные

Сейчас — только `data.js`, всё вымышленное. Для настоящей версии источник:

- вакансии — из формы «Разместить» (после модерации) и, возможно, из Telegram-каналов;
- резюме — из формы на `resume.html`;
- компании — из карточек работодателей.

## Что решить до перехода к бэкенду

- Хранилище вакансий и модерации (база, админ-панель или таблица).
- Авторизация работодателя и соискателя.
- Отправка откликов: почта, Telegram или сохранение в базе.
- Хостинг статики: GitHub Pages подходит, пока нет бэкенда.
